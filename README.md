基于FastAPI/LangChain/MySQL/Chroma/Vue，结合RAG与MCP工具调用的课程智能助手;
实现账号注册/登录以及JWT鉴权；
管理员可进行课表、课程、资料、学生信息管理；
学生可通过课程助手查询本人课表、询问课程资料、生成并保存学习计划；
页面实时展示工具调用过程和流式回答。
